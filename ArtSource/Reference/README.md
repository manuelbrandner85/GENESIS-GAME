# Referenzarchiv

Nach Doc 00b (Visual Reference, Quality & Cleanup Protocol). Referenzen bleiben von den Spiel-Assets getrennt und
liegen nur lokal (öffentliches Repository, fremde Lizenzen). Jeder Ordner mit Bildern führt eine `QUELLEN.md`:
Datei, Herkunft, Urheber, Lizenz, Seite. Analysiert und verwendet werden sie in den Reference Boards (Doc 36).

| Ordner | Inhalt |
|---|---|
| `Human/Baby`, `Human/Child`, `Human/Adult`, `Human/Elderly` | Menschen je Lebensalter: Haut, Haare, Augen, Hände, Haltung, Mimik |
| `Biology/…` | Embryo, Fetus, Zellen, Gewebe, Plazenta – wissenschaftlich belastbar (`Biology/Embryo`: Tag 15–28, GENESIS-041) |
| `Nature`, `Weather` | Landschaft, Vegetation, Wasser, Wetter |
| `Architecture`, `Materials`, `Historical` | Gebäude, Oberflächen, Epochen |
| `Cinematography`, `Lighting`, `Animation` | Kamera, Licht, Bewegung |
| `Cosmos` | reale Aufnahmen (NASA/ESA) als Grundlage des Kosmischen |
| `Concept` | **keine Realitätsreferenz**: KI-Zielbilder (`Concept/kie`, erzeugt mit `Tools/Reference/kie_reference_images.py`) |
